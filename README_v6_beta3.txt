КИНО-МЕНЕДЖЕР v6 BETA 3

Что нового:
- мобильная статистика 2x2, больше не обрезается справа;
- больше нижний safe-area для Safari/iPhone;
- компактное пустое состояние избранного;
- «Высокий рейтинг» расположен выше пустого избранного;
- «Сегодня вечером»: выбор из списка, поиск, карточка на главной, очистка, открыть;
- из карточки фильма можно отправить позицию «На вечер»;
- «Двойной сеанс»: случайный фильм + сериал из непросмотренных, можно перегенерировать;
- версия убрана из пользовательской логики и перенесена в «Профиль → О приложении» (в шапке Beta пока оставлена для тестов).
