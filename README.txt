МОЙ ВАТЧЛИСТ PWA v3

Добавлен поиск и автоматическое заполнение новых карточек через TMDB API.

1. Открой приложение через GitHub Pages.
2. Нажми «🔎 TMDB».
3. Вставь TMDB API Read Access Token и нажми «Сохранить ключ».
4. Введи название фильма/сериала.
5. Выбери результат → «Открыть карточку».
6. Проверь данные → «Добавить в мой список».

TMDB автоматически заполняет название, год, рейтинг TMDB, описание, жанры, постер, длительность, актёров, трейлер, IMDb и Кинопоиск. Для сериалов — сезоны и эпизоды.

Дубликаты проверяются по TMDB ID, а также по названию + году.
Ключ хранится только локально в браузере устройства.

This product uses the TMDB API but is not endorsed or certified by TMDB.
