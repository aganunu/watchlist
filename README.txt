# Мой ватчлист — iPhone PWA

В папке лежит готовое веб-приложение: `index.html`, `manifest.webmanifest`, `sw.js` и иконки.

## Важно для iPhone
Safari устанавливает PWA только из веб-страницы, открытой по HTTPS (или localhost). Открытие `index.html` через «Файлы» — это предпросмотр файла, и он не является полноценным PWA-контекстом.

Загрузите папку на любой статический HTTPS-хостинг (например GitHub Pages/Cloudflare Pages/Netlify), откройте адрес в Safari → «Поделиться» → «На экран Домой». После первого открытия приложение кешируется сервис-воркером и основные функции работают офлайн.

Данные и прогресс хранятся локально в браузере. Экспорт JSON позволяет переносить состояние между устройствами.
