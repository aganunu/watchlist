КИНО-МЕНЕДЖЕР v6 — UI PREVIEW

Это отдельный прототип интерфейса. Он не заменяет стабильную v5.6.3.

Заложено:
- mobile-first адаптация;
- телефон: нижняя навигация, горизонтальные карусели;
- планшет: 2x2 статистика и более широкие карточки;
- ПК: боковая навигация, широкая сетка;
- ТВ: увеличенные шрифты/кнопки и focus-visible для управления пультом;
- responsive размеры через CSS Grid/Flex/clamp/media queries;
- безопасные отступы iPhone через viewport-fit=cover;
- поиск и фильтры как интерактивный прототип.

Следующий технический этап:
перенести эту дизайн-систему на реальные DATA / localStorage / TMDB данные существующей стабильной версии.
